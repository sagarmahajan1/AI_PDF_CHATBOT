# 🤖 AI PDF Chatbot

An AI-powered Streamlit web application that allows users to upload PDF files and ask questions based on the content using Google Gemini API.

---

## 🚀 Features
- Upload PDF files
- Extract text from PDF automatically
- Ask questions in natural language
- Get AI-generated answers from PDF content
- Simple and interactive Streamlit UI

---

## 🛠️ Tech Stack
- Python
- Streamlit
- PyPDF
- Google Gemini API
- python-dotenv

---

## ⚙️ How to Run

```bash
git clone https://github.com/your-username/AI_PDF_CHATBOT.git
cd AI_PDF_CHATBOT
pip install -r requirements.txt
streamlit run app.py
